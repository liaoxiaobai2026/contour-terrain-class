把地形讲清楚

一堂课的演示顺序

  1. 在「认识地形」中点选部位，结合三维模型与右侧面板中的平面图观察。
  2. 先选择「单面切割」或「多面切割」。单面使用重点海拔的一个切面，多面为各等高线海拔配置切面。点击「① 切割」从画面右侧向左推进。可暂停、重播或拖动切割进度。
  3. 点击「② 描线」显示各层交线，海拔滑块选出重点海拔。可勾选「切去上部」观察该层截面；改变等高距，切面数量同步变化。
  4. 点击「③ 成图」，观察交线垂直投影后形成的平面等高线图。移动「向下投影」滑块可回看投影过程。
  5. 选择画笔圈画；点击「保存课堂网页」，下载包含视角、图层、课堂名称和批注的新 HTML 文件。

操作与文件

左键旋转；滚轮缩放；右键或 Shift + 左键平移。触屏可单指旋转、双指缩放。V 观察，P 画笔，E 橡皮，T 俯视，0 复位，空格播放，Ctrl / ⌘ + Z 撤销批注。

批注固定在屏幕上；旋转后不会跟随地形。画笔模式暂停旋转，可切回箭头继续观察。「保存图片」导出当前画面 PNG。「载入课堂」读取本网页保存的 HTML 或课堂 JSON，不执行导入文件中的脚本。

五种地形部位的判读

山峰等高线闭合，数值一般由外向内升高。仅看闭合形状还需结合高程，区别于洼地。
山脊山体向外伸出的高起部分。等高线向海拔较低处凸出。
山谷两侧较高、中间较低的狭长低地。等高线向海拔较高处凸出，可能成为汇水通道。
鞍部相邻两个山峰之间较低的部位；沿两峰连线较低，横向比两侧的谷地高。
陡崖近于直立的坡面。在本模型的理想垂直崖面，多条等高线在平面投影中重合。一般陡坡则表现为密集。

投影与图层

山体、切割面和等高线可分别开关。单面模式只显示当前海拔的切面与随切割逐渐形成的橙色交线，不显示其他海拔的等高线；海拔滑块可改变单面高度。右侧海拔标尺与模型使用相同投影，放大时变长、缩小时变短，也会随视角倾斜变化；近俯视时以等高线数值判读海拔。「仅看等高线」隐藏山体与切面，保留立体等高线，再点一次可返回山体。五种部位标注各有按钮，总开关可同时隐藏主图和小地图中的名称、指示线与编号。切去上部仅在切割面打开时生效。

山体具有细尺度自然起伏、坡面浅沟、弯曲崖壁和崖脚碎屑坡，采用程序生成的植被、风化岩石与光影材质，色彩不等同于分层设色，海拔以等高线数值为准。切割方向按动画启动时的视角确定，默认从画面右侧向左侧推进。本地形是专为教学构造的示意模型，无真实地理坐标，垂直比例经过夸张；图示海拔单位为米。网页内已包含全部代码，无外部资源、账号或网络请求。自动暂存依赖浏览器本机存储，跨电脑或长期留存请使用「保存课堂网页」。
